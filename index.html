02What matters most

  1. The $15.99 state fee is a pure e-file access fee — charged even on a $0 return.

    A California nonresident return with zero CA-source income and $0 CA tax still lands at a checkout of “Federal FREE + California State Return $15.99.” FreeTaxUSA monetizes the act of filing a state return, not tax complexity.

  2. The paywall is state-dependent — no-income-tax states never see it.

    For the Wyoming-resident persona, FTU says “Good news! Wyoming doesn’t require you to file a state income tax return” and refuses to even create a chargeable WY return. Filers in WY, TX, FL, NV, WA, SD, AK, TN escape the fee entirely; everyone else pays $15.99 per state to e-file.

  3. Paid interstitials sit at section seams, tuned to momentum.

    Deluxe ($7.99) fires right after Personal info; a full-screen Pro Support gate ($64.99) sits exactly on the Income→Deductions transition; Pro appears again as a card before Review. All declinable in one click — but Pro Support is pitched three separate times in one filing.

  4. The W-2 form is the heaviest single screen in the product.

    ~13 required fields plus ~40 optional ones on one page — a full paper-W-2 replica. Contrast candidate for any competitor that chunks W-2 entry into steps.

  5. Credits are screened one question per screen — ~13 screens of yes/no.

    Most default to “No,” but two (college expenses, home energy) have no default and force an explicit click. Long but low-effort; it inflates screen count more than actual effort.

  6. Validation is soft where it should be, hard where it must be.

    ZIP↔state mismatches hard-block with a plain-language message; an invalid-format EIN produces a yellow advisory (“an alert doesn’t mean you’ve done something wrong”) that lets the filer proceed. Good pattern for edge-case data.

  7. 2025 tax-law changes are surfaced as dedicated screens.

    Per-employer Tips & Overtime deduction screener, new-car-loan-interest deduction, and the digital-asset question each get their own screen turn.

  8. Sessions die after ~6–8 idle minutes.

    Server-side timeout with full credential re-entry and a forced re-prompt (?PRMPT) on the homepage sign-in link — real friction for any filer who steps away mid-return.

  9. The free federal path is genuinely instrument-free.

    With a $0 cart, no card or bank form ever appears. The only money decision left is paying the IRS itself — where the credit-card option carries a 2.5% third-party surcharge and is listed first; free IRS Direct Pay is listed last.

  10. Remove the state return and it chases you to the finish line.

    Cart removal triggers a save-the-sale dialog (“Keep my CA return” as the primary button, plus a questionable “you’ll still need to file your CA return by April 15, 2026” claim for a $0-liability nonresident) — followed by four separate add-back pitches: a “ready to file” product card, an order-summary note, a formal Tax Return Alert, and a numbered step inside the review checklist.

  11. A fourth paid product fires after checkout.

    A dedicated Audit Defense interstitial ($19.99, “10K+ bought in past week”) appears once the order is done — a second bite at the wallet post-cart. Completion itself, by contrast, is one clean control: an explicit “I understand” attestation plus a single “Finish Tax Return” button.

  12. FTU pre-validates e-file eligibility instead of letting the IRS bounce you.

    The invalid-format test EIN produced “Unfortunately, your federal return isn’t eligible for e-file — we’ll help you mail your return instead,” routing to the print-and-mail path up front. User-protective, and clearly communicated at the filing-method step rather than after a rejection.

04The state-fee story, end to end

The scope was extended beyond the federal-only default specifically to answer: what does the $15.99 actually buy, and who has to pay it?

Wyoming resident → no fee possible. FTU detects residency, announces no state return is required, and bounces an explicit attempt to add a WY return.  →  Add a California nonresident return (the persona’s employer is a CA company) → ~22 screens of residency, allocation ($0 CA-source income), CA-specific screeners → a valid CA return computing $0 tax → checkout: $15.99 anyway.
The terminal artifact: the full “Unlock more benefits” order page. Federal stays free; the state return is the product. For a filer whose state return is required, this is an unavoidable gate to e-file — even at zero state liability. (Run stopped here; no payment or filing action was taken.)

06The completion edge — Final Steps, end to end

FTU frames completion as a three-step stepper: Order Products → Review Tax Return → Submit Tax Return. This walk removed the optional CA return (restoring the $0 free path), declined every offer, chose zero-data IRS payment options, and ended on the last screen a filer sees before their return is complete — captured, never clicked.

The terminal artifact of the whole traversal: “Let’s send in your tax return!” — an explicit attestation checkbox (“I understand that I’ll need to print and mail in my taxes,” left unchecked) and the single completion control, “Finish Tax Return” (not clicked). One checkbox, one button: the cleanest moment in the product. Note the path is mail, not e-file — see below.

07Methodology & caveats

Setup. Live FreeTaxUSA production build, desktop web (1440×900), captured September 4, 2026 (off-season, TY2025 product). One traversal per cell; agent-driven navigation with human-in-the-loop for all authentication. Synthetic persona: single filer, one W-2 (wages $48,062, box-10 dependent care $5,000, 401(k) + Roth deferrals), no dependents, standard deduction, Wyoming resident.

Counting rules. A screen turn is any full content change requiring user action (page loads, SPA swaps, full-screen interstitials). Clicks are the minimum legitimate free-path actions, including upsell declines. Sign-in/re-auth screens are logged but excluded from headline totals (they were triggered by tooling idle time, though FTU’s ~6–8-minute session timeout is itself a real finding). Test-data corrections (two ZIP↔state fixes, one invalid-format EIN) are documented as data fixes, not product friction.

Hard limits honored. No return was filed, transmitted, or attested; no payment information was ever entered anywhere (product cart reached $0; the IRS balance was assigned to a mail-in voucher, a choice that collects no data). The state checkout was captured, then the optional CA item was removed to walk the free path; the Final Steps walk ended at the “Finish Tax Return” control without clicking it, its attestation checkbox left unchecked. E-file was independently blocked by FTU’s own validation (invalid-format test EIN), so no transmit control was ever reachable on this run.

What this is not yet. This is one of four planned traversals (FreeTaxUSA and a competitor, desktop and mobile web each). Cross-product comparison, per-phase pairings, and recommendations ship in the final report. Identity-bearing screenshots (and one screen showing an account phone number) are withheld from this public interim page.
